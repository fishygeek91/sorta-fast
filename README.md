# Sorta Fast 🏁

*Shortest paths that only sorta sort. That's not a joke, that's the algorithm.*

Watch 67 years of shortest-path history race on the same graph, in your browser, in real time — Dijkstra (1959) vs the sorting-barrier breakers: BMSSP (STOC 2025) and DMSY (Feb 2026, first public implementation).
